Perekam Template Pose Huruf (Alat Internal)

Alat internal untuk merekam pose acuan 21 titik MediaPipe Hands yang dinormalisasi (cv-core.js) dan menghasilkan query SQL siap salin untuk tabel template_pose di database.

Halaman ini dibuka langsung dari file (file://). Akses kamera mungkin diblokir browser. Jalankan lewat web server lokal (misal: http://localhost:8000/rekam-template.html).
