## Alur Kerja Branch
- `main` = versi stabil, jangan push langsung kecuali perubahan kecil (README, dll)
- Tiap fitur baru: buat branch dari `main`, format nama `namaorang/fitur` (misal `rifky/modul-cv`)
- Kerja & commit di branch itu, push ke branch itu (bukan `main`)
- Setelah fitur stabil: buat Pull Request ke `main`, review sebentar, lalu merge
- Setelah merge, `git pull origin main` sebelum bikin branch baru berikutnya
